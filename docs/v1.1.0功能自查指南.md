# v1.1.0 功能自查指南

> 面向"用模拟器/真机逐项确认功能对不对"。
> 已在 **release 包**上验证过的项标了 ✅ 并附证据；其余是需要你确认的。

---

## 环境准备

```powershell
$sdk="C:\Users\Administrator\AppData\Local\Android\Sdk"
$adb="$sdk\platform-tools\adb.exe"

# 模拟器（若已退出）
& "$sdk\emulator\emulator.exe" -avd Pixel_7 -no-boot-anim -gpu swiftshader_indirect -memory 3072

# 等启动完成
& $adb wait-for-device
while((& $adb shell getprop sys.boot_completed).Trim() -ne "1"){ Start-Sleep 3 }

# 解锁（Pixel 是上滑）
& $adb shell input keyevent KEYCODE_WAKEUP
& $adb shell input swipe 540 1800 540 600 200
# 检查期间别黑屏
& $adb shell settings put system screen_off_timeout 600000
```

装正式包：

```powershell
& $adb install -r "G:\android\AndroidGuo\yanhuo-short-v1.1.0.apk"
```

> ⚠️ **这个会话里模拟器会被环境回收**（我试过 4 次、两种启动方式，都在几分钟内正常退出）。
> 如果设备中途消失，重跑上面的启动命令即可 —— App 与数据都还在。

## 六、自动升级（需要公网环境，模拟器验不了）

清单：`https://raw.githubusercontent.com/chinut/yanhuo-short/main/docs/update-manifest.json`

当前 `versionCode=4` 与安装版相同，所以**不会**提示更新。
要试弹窗，二选一：

**A. 改远端清单**（会短暂影响真实用户）

```powershell
# 把 docs/update-manifest.json 的 versionCode 改成 999，提交；测完改回来
git add -A; git commit -m "临时：把清单版本号改成 999 用于联调"; git push
```

**B. 用调试包 + 广播**（推荐，不影响线上）

```powershell
& $adb install -r "G:\android\AndroidGuo\app\build\outputs\apk\debug\app-debug.apk"
# 把清单地址临时指到任意可访问的 JSON
& $adb shell am broadcast -a com.chinut.yanhuo.DEBUG `
    --es cmd check_update --es url "<清单地址>"
& $adb logcat -s Yanhuo:V | Select-String "Update"
```

**完整升级链路**（下载 → 弹安装器）必须真机 + 公网：

```powershell
# 看是否发现新版
& $adb logcat -s Yanhuo:V | Select-String "发现新版本"
# 点「立即更新」后看下载
& $adb logcat -s Yanhuo:V | Select-String "更新包下载完成"
# 若提示"请先允许安装未知应用"，去设置里打开再回来点
```

## 七、已知限制（不是 bug）

| 现象 | 原因 |
|---|---|
| 升级弹窗不出现 | 清单版本号与当前相同（正常） |
| `run-as com.chinut.yanhuo` 失败 | release 包不可调试，**预期行为**；要看文件得用 debug 包 |
| 离线页空 | release 与 debug 包数据隔离，各自独立 |
| 下载速度约 500~700 KB/s | 模拟器 + 源站 CDN 限制，真机会快 |
