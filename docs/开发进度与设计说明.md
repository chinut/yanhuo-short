## 三、待做 / 已知限制 ⬜

### 1. 红果的付费墙（**不是 bug，是站点限制**）

红果官网每部剧只有前 3 集有直链，第 4 集起 404。
**它已经不是主源了**，只在七猫没收录某部剧时兜底。
详见 [短剧源全量排查.md](短剧源全量排查.md)。

### 2. 主源没有"浏览全部"接口

七猫接口**只能按名字搜**（无参数 / `type=` / `id=1` 全都不行），所以：

- 首页推荐流 = 48 个题材热词轮转（每个词实测能翻 12 页）
- 热门榜 = 8 个高热词各搜一页，按 `hot_value` 折算数值排序

这是**接口能力决定的**，不是实现偷懒。代价是热门榜首次加载要 8 次请求
（已做进程内缓存，且放在瀑布流之后加载，不阻塞首屏）。

### 3. 自动联播未做"等待一集真正播完"的实机验证

代码路径完整（`STATE_ENDED` → `switchEpisode(index+1)`），
但短剧一集 2~3 分钟，没在模拟器上守完一整集。**建议下一轮优先实测这条**：

```powershell
# 起播后等一集播完，观察日志
adb logcat -s Yanhuo:I | Select-String "播完|自动播第"
```

### 4. 未做

- **下载 / 离线缓存** —— 需求没提，且播放地址带时效，缓存策略要另设计
- **倍速播放** —— 短剧用户常用；加的话在 `PlayerScreen` 底部加 1.0x/1.5x/2.0x 切换
- **投屏 / 分享** —— 未涉及
- **观看历史云同步** —— 纯本地
- **源可插拔的外部配置** —— 目前加源要写代码（一个 `Source` 实现，约 200 行）。
  如果找到更多公开 JSON 接口，可以考虑做成配置驱动

## 四、调试入口（仅 debug 包）

`DebugBus` 监听 `com.chinut.yanhuo.DEBUG`，**release 包不注册这个接收器**。

为什么需要它：主界面上的搜索图标、底部 Tab 都是**只有图标没有文字**的控件，
`uiautomator dump` 拿不到坐标，`input tap X Y` 只能靠猜（实测猜了三次都没点中）。
有直达命令，验证才变成确定的事。

```powershell
adb shell am broadcast -a com.chinut.yanhuo.DEBUG --es cmd open_search --es keyword 总裁
adb shell am broadcast -a com.chinut.yanhuo.DEBUG --es cmd open_tab --ei index 2
adb shell am broadcast -a com.chinut.yanhuo.DEBUG --es cmd set_source --es source qimao
adb shell am broadcast -a com.chinut.yanhuo.DEBUG --es cmd open_detail --ei index 6 --es source sub
# 需要播放器在前台
adb shell am broadcast -a com.chinut.yanhuo.DEBUG --es cmd play_episode --ei index 4
adb shell am broadcast -a com.chinut.yanhuo.DEBUG --es cmd open_episodes
```

## 五、发布到站点

这个 App 挂在自建站点上，**发布路径和版本号有两个地方要同步改**，漏一个用户就会下到旧包：

| 改哪里 | 改什么 |
|---|---|
| `app/build.gradle.kts` | `versionCode` **必须 +1**（否则覆盖安装会被系统拒绝）、`versionName` |
| 服务器 `WWW/YXDX/yanhuo_dl.php` | `yanhuo_apps()['short']['ver']` 和 `['file']` |
| 服务器 `Extensions/yanhuo-apps/` | 放新的 APK 文件（**站点目录之外**，只经 `yanhuo_dl.php` 下发） |

```powershell
# 1. 构建
$env:JAVA_HOME="E:\Program Files\Android\Android Studio\jbr"
.\gradlew.bat clean :app:testDebugUnitTest :app:assembleRelease

# 2. 上传（注意是 D$ 管理共享 + Extensions 目录，不是 WWW）
$dir = "\\web-server\d$\YXDXWebServer\phpstudy_pro\Extensions\yanhuo-apps"
Copy-Item .\app\build\outputs\apk\release\app-release.apk "$dir\yanhuo-short-v1.0.1.apk"

# 3. 改 yanhuo_dl.php 里的 ver / file（页面上的版本号和大小会自动跟着变）

# 4. 验证（HTTP 会被 CA 门槛 302 到 ca.php，所以本地必须用 https + -k）
curl.exe -s -I -k "https://web-server/yanhuo_dl.php?app=short"     # 看 Content-Disposition 里的版本
curl.exe -s -o NUL -w "%{http_code}`n" -k -H "Range: bytes=1000-2999" "https://web-server/yanhuo_dl.php?app=short"   # 应为 206
```

**踩过的坑**：

- vhost 把 `WWW/YXDX` 直接当**根目录**，所以地址是 `http://<host>/yanhuo.php`，
  **不是** `/YXDX/yanhuo.php`（多写一层会 404，我一开始就写错了）。
- 下载目录在 `Extensions/yanhuo-apps`，由 `CA_AUTHORITY_DIR . '/../yanhuo-apps'` 推导。
  换机器或改 `config.php` 时要重新确认这个推导。
- 本机没有客户端证书，走 HTTP 一定被 `ca.php` 拦下（302）。要端到端验证只能用 HTTPS。

## 六、踩过的坑（别重复踩）

1. **`<bitmap>` 不支持 `scaleType="centerCrop"`**（那是 ImageView 的属性）。
   开屏窗口背景只能用 `android:gravity`，合法值是 `fill` / `center` 之类。
   写成 `centerCrop` 会**编译期资源链接失败**。
2. **Kotlin 里"命名参数之后的尾随 lambda"会被拒绝**。
   `PillButton(text = "x") { ... }` 报 `No value passed for parameter 'onClick'`，
   非常费解。所以 `PillButton` 的 `onClick` **必须放最后一个参数**。
3. **`LaunchedEffect` 里注册的播放器监听器会永久捕获注册那一刻的状态**。
   直接读 `index` 会永远是初始值 → 表现是"自动联播每次都跳回第 2 集"。
   必须用 `rememberUpdatedState`。
4. **锁不要包住网络请求**。`SourceRegistry.fallbackEpisodes` 里一开始用
   `mutex.withLock { ... 发 HTTP ... }`，会把并发的每集解析全部串行化，
   而且请求一挂住整个回退链路永久卡死。
5. **`SharedPreferences` 里存不下大列表**。片库/收藏/进度全部走文件（`TsvFile`），
   SharedPreferences 只放开关和小字段。
6. **写文件要"临时文件 + 改名"**。手机随时可能被杀进程，半截文件解析出来是
   "半份列表"，比空还糟（用户以为内容丢了）。
7. **跨源匹配宁可失败也不要猜**。七猫搜「首辅娇娘」返回的是
   《休病夫，她转身嫁首辅》这类**相关但不是同一部**的剧。
   如果随手取第一个，用户点第 4 集会看到另一部剧 —— 比"看不了"糟糕得多。
8. **模拟器 API 37 镜像的 WiFi 起不来**（`ip addr` 只有 `lo`），
   但 `ping` 不可用**不代表没网** —— App 实际能正常联网取数据。
   别用 `ping` 判断模拟器网络。
