# 焰火短视频（AndroidGuo）

手机端竖屏短剧 App。内容来自**第三方公开网页接口**，本 App 只做播放器与界面聚合，
不存储、不传播任何影视资源。

> **核心诉求：能全部看。**
> 所以主源选了实测**每部剧都给全集直链**的七猫短剧，而不是只免费前 3 集的红果。

---

## 数据源

| 角色 | 源 | 能力 |
|---|---|---|
| **主源** | 七猫短剧 `xiaoqi.icofun.cn` | **713 部，每部全集直链**（96 集的剧 96 集全有地址） |
| 备用源 | 红果短剧官网 `hongguoduanju.com` | 每部剧只免费前 3 集（第 4 集起 404），仅在主源没收录时兜底 |

### 主源实测（这是选它的唯一理由）

```
《潜龙出山，闪婚美女总裁》
  标注 96 集 → play_list 96 条 → 96 条全部有非空地址
  抽查 第 1 / 49 / 96 集 → HTTP 206 application/vnd.apple.mpegurl
  备案号：（七猫）网微剧备字（2025）第01177号
```

App 内实测（release 包，Pixel 7 / Android 17）：

```
[SourceRegistry] 第 1 集  ← 七猫短剧（直取）
[SourceRegistry] 第 10 集 ← 七猫短剧（直取）     ← 红果在这一集是 404
```

### 接口

```
https://xiaoqi.icofun.cn/API/qimao_duanju.php
  ?name=关键词&page=N   搜索（一页 10 条，单关键词可翻 12 页）
  ?id=短剧id            详情 + 全部集直链（play_list）
```

⚠️ 接口**没有"浏览全部"**，只能按名字搜。所以首页推荐流是
"48 个题材热词轮转"（热词用完进第 2 页）；热门榜是拿 8 个高热词各搜一页、
按条目的 `hot_value` 折算成数值排序得到的。

> 关于其它源（红果付费墙、黄果/野果/帝果、GitHub 上的"开源短剧源"、
> 苹果CMS/TVBox 生态）的完整排查记录见
> [短剧源全量排查.md](docs/短剧源全量排查.md)。

## 功能

| 模块 | 说明 |
|---|---|
| **主页** | 两列瀑布流，卡片**标注集数**；顶部「热剧榜」横滑，前三名金色名次角标；无限翻页 |
| **搜索** | 走**源接口搜索**，滚到底自动翻页 |
| **播放器** | 竖屏全屏、**自动联播**下一集、**断点续播**、选集抽屉、拖动进度 |
| **收藏** | 卡片/播放页一键收藏，收藏页统一管理 |
| **连载订阅** | 订阅后每 6 小时后台检查集数变化，有新集发通知 + 应用内红点 |
| **我的** | 观看历史、数据源自检、播放/通知开关、运行日志、存储清理 |

## 构建

```powershell
$env:JAVA_HOME="E:\Program Files\Android\Android Studio\jbr"
.\gradlew.bat :app:assembleDebug      # app/build/outputs/apk/debug/app-debug.apk
.\gradlew.bat :app:assembleRelease    # app/build/outputs/apk/release/app-release.apk
```

## 功能开关

设置 → 我的：

- **主源取不到时用备用源兜底**（默认开）
- **自动联播下一集**（默认开）
- **断点续播**（默认开）
- **竖屏铺满**（默认开）
- **有新集时通知我**（默认开）
